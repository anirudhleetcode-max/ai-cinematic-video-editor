# Procedural textures

All four PNGs are **tileable** (they wrap seamlessly in X and Y) and were generated by
`cmet/core.py fft_noise()` (spectrally-shaped random noise). They are optional: no template
requires them - every template builds its textures procedurally inside the Fusion graph
(FastNoise, gradients) or inside the reference renderer. Use them with a Fusion *Loader* if you want
to swap a look (e.g. as a Bitmap mask or Overlay layer).

| File | Character |
|---|---|
| fog_tile_1024.png | Soft low-frequency fog / haze |
| smoke_ridged_tile_1024.png | Ridged wisps (smoke filaments, energy) |
| stone_grain_tile_1024.png | Fine mineral grain (stone, concrete) |
| brushed_metal_tile_1024.png | Horizontal brushed streaks (metal) |
