# Ayurvedic Diet Platform — hackathon pitch film

The edit project for the team's pitch video. It turns two raw presenter takes into one graded pitch film with motion graphics.

## Deliverables

| File | What |
|---|---|
| `renders/` (not committed; too large for git) | `pitch_final_1080p.mp4` (H.264 High, 1080p30, 48 kHz stereo) and `pitch_preview_720p.mp4` |
| `docs/EDL.md` | Edit decision list / timeline |
| `docs/TRANSCRIPT.md`, `docs/transcript.srt` | Timestamped transcript, plus optional subtitles |
| `docs/ASSETS.md` | Which asset is used where |
| `docs/NOTES.md` | **Items to confirm** (team name, clipped word), QC log |
| `studio/` | Remotion project: every graphic, timing and camera move is editable code |
| `pipeline/` | ASR, denoise, upscale, matte/grade and audio-mix scripts |

## Re-editing

```bash
cd studio && npm install
npx remotion studio src/index.ts          # live preview / scrub timeline
# change TEAM_NAME etc. in src/config.ts, timings in src/scenes/*.tsx
npx remotion render src/index.ts Pitch ../renders/pitch_raw.mp4 --muted --browser-executable=<chrome-headless-shell>
```

The presenter plates (`studio/public/plate*.{mp4,mov}`) are generated by `pipeline/` and are not committed:
`upscale.py` (Real-ESRGAN general-x4v3, bf16) → `matte.py` (grade + Robust Video Matting) → `audio_mix.py` (DeepFilterNet3 denoise output + EQ/comp/loudnorm + synthesized score and SFX, ducked under voice).
The final pass in ffmpeg adds grain, a light vignette and the audio mux.
